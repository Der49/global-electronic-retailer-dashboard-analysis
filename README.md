# Global Electronic Retailer Dashboard Analysis

Analyzing sales data for a fictitious global electronics retailer, including tables containing information about transactions, products, customers, stores and currency exchange rates.

---
## 📌 Business Overview

We will find patterns through which categories, products, stores, and countries that drives revenue and profit, how have they trended over time, and how do customer demographics and purchase behavior shape those results so that we can use Data-Driven Decision-Making in the business.
